# Chao Garden 0.25.6

Both garden stairways now follow the lobby wall. The celestial tread and landing surfaces match the lobby floor, while continuous guards close the exposed edges and turns. Obsolete blocks beneath the former Hero approach are removed during the room refresh. Each garden retains its own portal and return landing.

The gates use the supplied game pictures as their primary references. Hero has gold shafts, ornamented ivory capitals, halo-topped orbs and winged Chao statues. Dark has a purple-grey masonry arch, pale bands, blue-violet sconces and horned Chao statues with tridents. Their openings remain usable from the stairs and their return landings.

Dark Garden fruit attach to visible deadwood branches. Fruit block identities and harvesting/regrowth remain intact. Tombstones keep their Chao engravings on the front and back, with plain stone on their narrow sides, stepped tops and undersides.

Ionic capitals have smaller square plates above the scrolls so the volutes remain visible. The shaft ribs are inset to align with the supporting base without overhanging it.

Install the same `chao_garden-0.25.6.jar` on the server and every client, replacing the previous JAR. Minecraft Java 1.21.1, NeoForge 21.1.219 and Java 21 remain required. Accessories and owo remain optional. See [TESTING.md](../TESTING.md) for the final verification scope.

Dark Garden remains a first pass, including its red-tinted native-water waterfall. Existing garden care, ownership and original-world return data are retained. The complete project includes the supplied reference pictures and current verification logs. Screenshot and video previews are omitted at the user's request.

# Imported Chao anatomy and motion — 0.15

> Historical 0.15 implementation record. Native conversion, surface behavior and pose fitting were revised in 0.18 and 0.19; current source and [MECHANICS.md](../MECHANICS.md) take precedence over older formulas or limitations below.


The current base Chao anatomy, texture maps and eight animation clips come from the owner-supplied Gamemode One Sonic the Hedgehog resource pack. Only asset authoring inputs are retained under `art/imported_chao/`: twenty Bedrock geometry JSON files, twenty matching PNGs and the Chao animation JSON. Account files, entitlement data, content manifests and access keys are not part of that authoring directory or the mod.

Run `python3 art/import_official_chao.py` to rebuild the converted runtime meshes, source textures and UV-matched inherited/shiny coats. The importer's optional `--source` argument accepts an already readable resource-pack root; it does not perform account/key handling. `--skip-coats` rebuilds the source geometry/texture/animation portion quickly.

The twenty `.geo.json`/`.json` source geometries can be opened as Bedrock models in Blockbench. The earlier `.bbmodel` projects remain authoring inputs for our custom additions and cocoon; their old base body is not the currently rendered ordinary Chao.

The native asset conversion preserves global source bone pivots as parent-relative pivots and gives every source cuboid an independent child bone. It retains mirrored UV winding, per-cube pivots and rotations, source inflation, and nondegenerate faces of zero-thickness planes. The mesh coordinate conversion is X=-X, Y=24-Y, Z=Z. Bedrock's left-handed angle convention becomes Java rotations (+X,+Y,-Z). Logical UV dimensions remain64x32 even when the source image is128x64. A few unused question/dizzy glyphs have authored U coordinates outside64; these coordinates remain preserved, and those unused glyphs are hidden by the state controller.

`OfficialChaoRig` samples the exact supplied clips using linear source keyframes and the small Molang expression subset those clips require: degree-based sine/cosine, animation time, the current channel value, carrying state and swelling scales. Movement blends idle/walk; care reactions choose happy/sad/alert/ordinary marker. Native creature forms use the closest matching source anatomy. Alignment/type combinations absent from the supplied set use the relevant source ability rig with a derived coat. Inherited colors, shiny/jewel coats, mod themes, animal parts and all three Chaos appearances keep their saved-state semantics. The source's own Minecraft-specific specials remain available in the rig implementation without adding unrequested collectible IDs to the active catalog.

Our mod crowns, fitted goggles, badges, markers, animal parts and Chaos features are separate retargeted overlays. They follow sampled source semantic anchors rather than being stuck to an unanimated body. Source face panels are retained while replaced head decorations or limbs are hidden. The Black Market trader uses the same Baby anatomy and idle/walk clips, with its separate shopkeeper coat and face markings. Eating, swimming, sleep, attack and cocoon behavior remain extensions for our care/competition/companion systems.

Validation is split deliberately. `scripts/validate_official_chao.py` checks source-relative pivots, cube bounds, native angle conversion, mirror winding, inflation, plane-face preservation and source byte equality. It currently passes19,746 checks across20 rigs,366 source bones,809 cuboids,63 mirrored cuboids,72 inflated cuboids,69 zero-thickness cuboids and4,576 nondegenerate faces. Exact source texture bytes and the eight-clip animation file match their authoring inputs.

The excluded `ReleaseVisualSmokeOfficialProbe` runs with the development release study inside an actual Minecraft client. It samples2,000 combinations across20 rigs and four emotion states, including walking/idle and the two special clips, checks finite poses, verifies lowered idle arm directions, and compares idle-loop endpoints. Its completion marker is `CHAO_OFFICIAL_POSE_PROBE_COMPLETE`. Actual rendered appearance still requires the client capture review recorded by the release's TESTING.md; numeric parity alone is not proof of final texture orientation or visual clearance.

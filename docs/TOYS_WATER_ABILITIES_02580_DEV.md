Operator previews do not add fear, care rewards or progression. Actual Sonic Adventure behavior was not independently re-recorded, so this report does not claim exact original-game choreography.

The glow came from full ambient MTL values interpreted as emissive by NeoForge's OBJ loader. The affected materials now use zero ambient and explicit non-emissive model settings. Shadow uses the existing imported source palette as a blocky texture reference, rather than claiming a recovered official Shadow mesh.

## Floating aids and save safety

- One entity holds the sole recoverable item stack. Legacy placed blocks convert transactionally on use; existing worlds are not bulk-rewritten. Failed placement, conversion, pickup or drop must retain or return exactly one source.
- Non-swimmers in water seek a nearby available aid; trained swimmers may use one voluntarily. Existing nonlethal water distress and normal swimming remain intact outside the interaction.
- Ground transport follows loaded, supported routes with a local pusher. Turns retain launch ownership while the Chao walks around the toy. Step-up is suppressed only during that owned push/reposition and returns to the ordinary value afterward.
- Boarding and exit take 16 ticks, using the same collision-tested arc for planning and movement. The arc accounts for the actual settled waterline, including downward entry from a bank.
- Landing requires a complete supported, dry, nonhazardous footprint, headroom and an inward escape corridor. The controller revalidates the destination at completion and eases back aboard if it disappears. With no safe route it keeps the rider afloat and retries instead of forcing a dismount.
- Occupied pickup/break requests end any operator preview immediately, restore its temporary AI state and request safe egress. The item drops only after the rider can leave safely. Preview stop can therefore clear the preview while the real passenger remains briefly aboard.
- Pending removal survives recursive passenger-tree reload. A transient restoration state permits the saved passenger to attach before publication, while new claims remain blocked. Normal published pending-removal admission stays strict.
- Client passenger admission now accepts the authoritative server passenger packet without depending on the server-only item payload. Server occupancy and payload checks remain strict.
- Ring collision height is 0.20; duck height is 0.68; both retain the 0.98 conservative horizontal hull. Real engine care rays can select baby and adult riders instead of an invisible ring box covering their faces.
- A completed natural ride awards the existing benefit once after 160 riding ticks: +4 happiness, -35 boredom, +20 joy and -2 energy. Paid/eligible state persists. Rescue, early interruption, previews and waiting for safety do not repeatedly award play rewards.

Deliberate boundaries: candidate search is eight blocks horizontally and four vertically; loaded route search is bounded to radius 12 and 512 nodes, and water-column inspection is bounded. Flat supported launch paths are handled; stair portage is not implemented. A deeply submerged Chao with a float more than four blocks above it is outside the current candidate window. One- and four-block water depths were exercised.

Known visual approximation: land transport is functional, but the stock short arm rig leaves a visible hand-to-toy gap, especially for the small ring mesh. Exact reach analysis found that closing it would require substantial lean and paired model/seat changes. Those changes were deferred rather than stretching limbs, reshaping the head or introducing clipping. The current visuals must not be described as verified palm contact. A focused transport-pose/model-fit follow-up is recommended.

## Secret equipped abilities — development only

No conditions, percentages or instructions for these easter eggs were added to the in-game guide, tooltips, language entries, normal README/changelog or player-facing messages.

| Ability | Eligibility and maximum effect |
|---|---|
| Speed | Living adult; locked first Run; exact single current adult specialization Run; expressed Run rank X (grade 6), level 99; any alignment. One +1000% total movement-speed modifier, replacing the ordinary Run modifier. |
| Power | Living adult; locked first Power; exact single current adult specialization Power; expressed Power rank X, level 99; any alignment. Actual native melee horizontal knockback strength receives +1000%. |

Current specialization uses the existing reversible axes and their existing label thresholds. Mixed Run+Fly/Swim or Power+Fly/Swim forms do not qualify under this exact-single-specialization interpretation. Age strength and energy do not add new secret gates. First evolution identity and adult alignment are not changed.

Crouching and pressing main-hand use on empty air cycles 1000, 900, ... 100, 0, 1000. Both hands must be empty, deliberately preserving normal off-hand use. The client uses a physical press/release latch; held repeats and off-hand callbacks cannot produce duplicate activations. The server independently validates the current authenticated equipped Chao, dimension, stale-intent UUID guard, sequence, four-tick debounce and actual loaded block/entity ray. The supplied UUID does not authorize or select another Chao.

Each Chao's optional setting is stored in its existing trait codec and snapshotted to its real carrier immediately. Missing/malformed data defaults safely to 1000. There is no new competing personality/genetics system or reroll. At eligible Run zero there is no companion speed bonus; becoming ineligible returns to existing ordinary companion rules. Unequip, reconnect and dimension transitions cleanly remove/rebuild effects while retaining the selected percentage. Existing carry previews remain a temporary suppression boundary.

Engine constraints were checked rather than relying on a displayed multiplier:

- +1000% means eleven times the normal base, not ten times. The ordinary player movement base is about 0.1, giving about 1.1; the native movement attribute maximum is 1024.
- ATTACK_KNOCKBACK defaults to zero and is capped at five. Multiplying that attribute would do nothing; adding ten would silently clamp. The implementation instead scales the scoped native player-melee knockback calls, once per actual call, preserving resistance, cancellation, PvP rules, damage and unrelated sources.
- Native motion packets clamp each component to +/-3.9. Identity/dimension/sequence-guarded double-vector corrections preserve larger legitimate impulses for the victim and trackers, after vanilla's PvP velocity restoration. Victim corrections stop below the packet limit. Marked player observers receive bounded current-vector updates until horizontal rest or an 80-tick deadline; these observer-only updates never reapply force to the victim. The receiver aligns the native interpolation target, and the marked native tracker cache remains current for late pairing. Unmarked ordinary PvP retains vanilla behavior; no world scan or permanent impulse modifier is installed.
- Vanilla also compares inbound movement with its current server velocity, which can already have decayed before the client applies the authorized impulse. The fix changes only that native expected-motion term for a completed authorized melee hit: same victim object, UUID and dimension, at most 20 ticks, eight recent coalesced server-velocity samples, and the native one-to-five-packet burst bound. Later motion cannot expand the authorized impulse cap. Collision, finite-coordinate and excessive-displacement checks remain active; unmarked, expired and dimension-changed players retain ordinary validation.
- Vanilla vertical knockback retains its 0.4 cap. The requested bonus applies to horizontal native impulse strength; it does not multiply flight height. Normal base 0.4 becomes about 4.4; sprint plus Knockback II produces about 18.7. Zero Power retains the ordinary attack impulse.

## Operator previews

Examples: `/chao testtoy jack_in_box once`, `/chao testtoy rocking_horse loop`, `/chao testtoy rubber_duck once`, `/chao testtoy lifesaver loop`, and `/chao testtoy stop`. Jack previews require its matching front seat within 0.4 blocks; riding toys need a real local source and a safe approach. Previews reuse the production controllers and restore temporary AI flags without care/progression rewards. Stopping a float preview releases preview ownership immediately; its passenger can remain aboard until safe land is reachable.

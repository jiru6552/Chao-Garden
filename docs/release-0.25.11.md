# Chao Garden 0.25.11

For Minecraft Java 1.21.1 / NeoForge 21.1.219 / Java 21. Replace the previous JAR on client and server. The supplied music is included directly; no separate sound pack is needed.

- **Waterfall side:** filled the bare lawn beside the cascade with a low, curved limestone bank topped with grass and nine more broad-leaf plants. The complete planting now has eighteen supported plants. The stream, receiving pool, eight palms and main lawn/exit routes remain.
- **Palm bark:** warmer brown bark with clear horizontal leaf-scar rings, fine grain and full-face UVs. The existing slim native trunk silhouette and collision are retained. Both Neutral and Hero authored palms use this shared bark.
- **Area music:** imported the supplied Battle lobby, Neutral Garden, Hero Garden, Dark Garden and kindergarten recordings. Area tracks remain stereo streams and follow the existing regional playback controls.
- **Classroom singing:** included all six supplied Hero/Dark singing tracks as full mono positional streams. One plays at a time; kindergarten background music fades out while classroom singing is selected and returns outside the classroom.

Authored-room revision 36 applies the landscaping update to existing worlds using the care-preserving migration path. Existing Chao, dropped items and purchased props retain the established migration protections. The separate jukebox recording and ordinary Chao voices are unchanged. Black Market music and individual learned solo singing are not added by this update.

# Theme icons and drive detail - 0.13.0

All four Chaos Drives retain their upright shape and striped metal endcaps. Two dark colored columns form a recessed central line through each crystal, following the supplied marked-up reference. Their training effects are unchanged.

All 48 themes have new original symbols based on recognizable mod objects, equipment or portals. Examples include the Create cogwheel, AE2 controller, Refined Storage disk, Thaumcraft goggles, Botania Terra Blade, Blood Magic orb and Aether portal. Each theme has an explicitly authored **8px egg mark** and a separate **16px chest badge**. The small symbols are not reduced from larger artwork. Canonical object colors are retained rather than tinting every symbol with the Chao coat palette.

The same theme identity routes both item and model art. All 48 existing themed eggs and all 48 themed body atlases use the new symbols. Head geometry, animal parts, ordinary egg shells, DNA vials and gameplay data remain as in 0.12. Mod themes still require their existing loaded mod IDs; Nether and End remain available without another mod.

These are original pixel-art tributes, not extracted textures. Primary mod reference links and all 48 motif choices are documented in the [technology](research/THEME_ICONS_TECH_013.md), [magic](research/THEME_ICONS_MAGIC_013.md) and [adventure](research/THEME_ICONS_ADVENTURE_013.md) notes.

The [current icon gallery](icon-refinement-gallery.html) includes real Minecraft frames plus separately labelled authored artwork. The [theme sheet](screenshots/theme-icons-0.13.png) shows each 16px badge, native 8px mark and final egg, with native-size examples. See [release validation](../TESTING.md).

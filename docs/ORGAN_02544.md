# Organ interaction 0.25.44

Based on the full 0.25.43 source: Minecraft 1.21.1, NeoForge 21.1.219, Java 21, Lionfish API 3.1. Install the matching Chao Garden and Lionfish versions on both clients and server. No duplicate organ item or new animation library is introduced. Piano, Analyzer, garden and Chaos Drive behavior is retained. The earlier held-item recovery test correction is included in this working tree.

## Interaction and geometry

The existing `chao_organ` uses its actual SA2 manual, not the piano coordinates. The idle OBJ's `sa2_piano01_20` key surface spans X 0.23512–0.79223, Y 0.18667, Z 0.39713–0.48796. Its keys face local north, ahead of the cabinet/pipes. Blockstate rotations carry that front to north/east/south/west. The existing front-only navigation and collision-checked anchor remain authoritative. A blocked key side prevents selection; neither side nor the back is a fallback. The existing reservation, 160-tick duration, reward, cooldown and voluntary selection remain in PlayGoal.

A dedicated Lionfish clip raises both hands, plays eight sustained two-hand chords at ticks 24, 40, 56, 72, 88, 104, 120 and 136, and lowers the hands. Hands move between neighboring keys during the lifted portion rather than sliding through a held chord. The renderer fits the actual skin, replacement or Chaos-layer palms to the organ manual after pose blending. It uses the existing happy-face priorities and a small head sway; damage suppresses the presentation immediately.

The cabinet and pipes no longer wobble with generic keyboard frames. Only the manual depresses 0.003 blocks during contact. `scripts/generate_organ_02544.py` generates these frames from the unchanged idle mesh and an original 0.60-second mono flue-pipe tone with a soft attack/release. Each chord emits a lower and upper pipe tone at its contact tick. Generic organ harp pulses are removed; the piano's harp and timing remain unchanged. Interruption stops new notes; already-emitted short tones retain their release tail (pitch-dependent, up to about one second).

## Operator previews

Place one organ within three blocks of a dry, idle Chao, with solid clear ground in front of the keys. Operator level 2 is required.

```mcfunction
/chao testtoy list
/chao testtoy organ once
/chao testtoy organ loop
/chao testtoy organ stop
/chao testtoy stop
```

These use the real placed organ, production Lionfish pose, synchronized contact clock and sound cues. They reserve the organ, pause care/age, grant no rewards or lessons, and preserve cooldown and the prior NoAI flag. They create no held toy item. Explicit stop, interaction, damage, toy removal, moving the Chao away, unload/reload, keeper logout or leaving the dimension/64-block range clean up the preview. Normal damage/petting effects retain their ordinary meaning.

## Reproduce checks

Use Java 21 and the checked-in Gradle 9.2.1 wrapper. The current build script needs `--no-configuration-cache` because its existing processResources task accesses Project during execution.

```sh
bash gradlew --no-configuration-cache assemble coreTest organTimingTest organRigTest pianoTimingTest pianoRigTest
python3 scripts/test_organ_assets_02544.py
bash gradlew --no-configuration-cache runGameTestServer -PchaoGameTestNamespaces=chao_organ44 -PchaoGameTestDir=/tmp/chao-organ44-fresh
```

The mesh test exercises 152,604 hand samples across shipped gameplay rigs, baby/adult sizes, development endpoints, replacement hands and separate Chaos glass palms. It checks source-key bounds, finite/bounded joints, key height, and independently emitted skin-hand vertices. Timing tests sample the actual Lionfish library. Asset checks validate the manual's front, stationary cabinet, key depression, sound decoding and amplitude/endpoints. The native organ suite covers all four orientations, baby/adult approach, a crawling baby at the keys, blocked fronts, real sound events, completion rewards, reservations and command/loop/interruption cleanup. Walking baby approach fixtures have the existing 50 Run-point milestone; they do not grant points in gameplay.

For an opt-in disposable graphical study:

```sh
bash gradlew --no-configuration-cache runClient -PorganVisualStudy=true
# Optional: -PorganStudyDir=/path/to/disposable-client
```

That study uses a fresh world under `run-organ044` (or `organStudyDir`; this cloud run used `/workspace/.setup/organ-client`), the native operator command, the production renderer, a baby, adult, rabbit-handed baby and Chaos form, four orientations, three camera angles, and additional damage/movement interruption sessions. It stores time-labelled native screenshots and checks session cleanup. The study/fixtures are excluded from the installable JAR.

## In-game acceptance

- Place north-, east-, south- and west-facing organs. Confirm approach to the visible keys, not the cabinet sides/back; block the front and confirm no interaction starts.
- Watch a baby, adult and animal-handed Chao from the side and above: both hands should meet the manual, hold chords and lower cleanly. Check a Chaos form's visible hands too.
- Listen at normal Friendly Creatures volume for the organ tone, chord timing, volume and release tails; compare several nearby instruments for overlap.
- Try once/loop/stop, petting, damage, moving the Chao away and removing the organ. Check the block returns idle and previews do not change age/care or award rewards.
- Verify another player sees/hears the same interaction. Full-modpack compatibility and separate-client latency/listening are manual acceptance checks.

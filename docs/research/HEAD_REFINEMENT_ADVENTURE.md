# Adventure head refinement — confirmed 1.21.1 NeoForge themes

Verified 2026-10-29 against publisher CurseForge project/file pages. “Confirmed” means a downloadable file whose page explicitly lists **Minecraft 1.21.1 and NeoForge**. This is availability research, not a claim that the third-party mods were launched together. Community ports are identified explicitly. Stable Chao theme IDs and existing gates remain unchanged.

## Availability and head direction

These are original art directions inferred from recognizable mod motifs. They are not copied meshes or promises of official affiliation. Replace the accessory head group with a connected skin silhouette, using one dominant head feature and a broad root transition into the skull; keep the face plane, Chao eye spacing and resting-arm clearance.

## Excluded from this pass

- `blue_skies`: publisher [file list](https://www.curseforge.com/minecraft/mc-mods/blue-skies/files/all) lists its newest official build as **1.20.4 NeoForge**, dated 2024-02-05. No confirmed 1.21.1 NeoForge file found.
- `betweenlands`: publisher [file list](https://www.curseforge.com/minecraft/mc-mods/angry-pixel-the-betweenlands-mod/files/all) lists its newest official line as **1.12.2 Forge**. Port work alone is not release confirmation.

## Visual reference pages

Publisher galleries/descriptions were revisited for the primary inspiration, with design interpretations above authored for the Chao rig:

- [Cataclysm](https://www.curseforge.com/minecraft/mc-mods/lendercataclysm): gallery labels include Ignis, Ignited Revenant, Ender Golem and Harbinger.
- [IceAndFire CE](https://www.curseforge.com/minecraft/mc-mods/iceandfire-ce): unofficial fork, retaining the dragon content of Ice and Fire.
- [Aether](https://www.curseforge.com/minecraft/mc-mods/aether), [Twilight Forest](https://www.curseforge.com/minecraft/mc-mods/the-twilight-forest).
- [Alex's Mobs Neo](https://www.curseforge.com/minecraft/mc-mods/alexs-mobs-neo): explicitly describes an unofficial port of the original creature mod.
- [Undergarden](https://www.curseforge.com/minecraft/mc-mods/the-undergarden): underground flora/creature imagery.
- [Deeper and Darker](https://www.curseforge.com/minecraft/mc-mods/deeperdarker): sculk, deeplands, echoing forest, overcast columns.
- [Quark](https://quark.vazkii.net/): Stoneling/Toretoise/Heart of Diamond motifs should be read as inspiration, not arbitrary gear.

All source file names and versions here are a research snapshot, not minimum-version checks in Chao Garden. Mod-list gates continue to match actual mod IDs from the existing catalog.

## Largest observed differences

1. Hero child anatomy differs from Neutral Run. The actual Hero-child screenshots from the access check have a central stem and small lateral buds, while Neutral Run develops swept rear points. Baseline mod case9 uses five long Neutral-style quills on a rectangular Hero head. The current user request to follow the viewer's Hero path takes precedence over the previous prototype's deliberate Neutral-silhouette-on-Hero interpretation. Run and alignment must remain separate continuous inputs; the two alignment-specific anatomical corners need not have the same silhouette.
2. Actual newly evolved Hero Run viewer10..15 is faceted with bevelled/rounded cranial outline and a narrow central stem, compact closed hands, broad shaped feet, a small violet belly center surrounded by blue then white torso, and a gold halo. Baseline case10 is a square head, almost absent thin stem, layered rectangular feet and a flat violet torso-front.
3. Actual mature HeroRunRun viewer20..25 has an integrated rear head point and THREE broad, thick curved crown petals sharing a branching stem. Above/back views show a three-prong fan. Baseline case15 retains a cuboid skull and detached-looking stepped narrow crown strips. Side and below views expose the mismatch.
4. Viewer mature feet broaden into coherent tapered pads and palms remain compact. Baseline mod limbs retain donor-index anatomy and angular layers/segments. New target vertices must have a deliberately authored common correspondence rather than assuming donor equal counts imply the same topology.
5. Viewer adult color regions evolve: blue/gold/white stem and limb bands, white torso surround, young violet/blue belly becoming a blue center with yellow rim at maturity/Run, yellow wings shifting toward teal. Current mod paints the entire torso-front violet and lacks matching region detail. Inherited coats currently bypass some semantic UV details; the same geometry/detail regions must work on every coat while preserving inherited colors/finish.
6. Viewer normal/Hero-child orb differs from the existing early Hero four-bar marker. Baby marker and adult halo should have deliberate stage-appropriate anatomy/colors while preserving emotional symbols. Closed hats must hide every added crown/point and exclude hidden geometry from fit bounds; overlay/animal/held/player attachment anchors must sample the same deformed rig.

## Integration decision

The current mesh loader already supports arbitrary triangle/polygon faces and shared named bind/palm/bounds sampling. No new library is warranted. Author one moderate-facet canonical path mesh with deliberately compatible baby/adult targets, recomputed deformed normals, stable facial inset/eyes and compact closed hands/feet. New.54 assets and renderer selection can leave prior source assets intact. Do not copy viewer runtime geometry or infer its hidden morph logic. Use verified original-file anatomical landmarks and adult-family correspondence as supporting measurements, not a child-to-adult vertex-index mapping.

Keep HeroRunMorphology052.Sample and existing provisional480/960 training denominators, separate biological maturity, four-stat earned-point/recency first evolution, adult alignment lock, secure Creative baby control and save encoding. No gameplay/data overhaul is authorized or needed.

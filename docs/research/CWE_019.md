## Concrete content implemented in this module

`CweCatalog`, `CweGiftItem`, `CweContent`, `FruitCatalog`, `FruitEffects`, `MarketStock`, `CweAccessoryLayer` and `art/build_cwe_content_019.py` supply13 foods and renewable orchards,10 extra gene samples,13 lenses,10 actual wearable accessories,9 other gifts,16 additional physical toy blocks and one hatch-only eggshell hat. Existing8 toys remain, giving24 total. The five added vanilla lesson instruments have no invented merchant price. Market stock rotates19 actual offers, including one CWE fruit, one accessory and one special gift; it does not expose the whole catalog at once. Existing stock remains save-stable.

Physical gift consumption uses the server think/use/commit pipeline. Accessories are actual saved/synced ItemStacks in five equipment slots: hat=HEAD,head accessory=FEET,face=OFFHAND,neck=LEGS,outfit=CHEST. Original names,dyes and custom components survive swaps, capture, companion use, save/reload and reincarnation. Replaced stacks are returned once. This is a bounded five-category Minecraft adaptation, not all64 arbitrary API accessory slots/channels from current CWE.

### Numeric and acquisition adaptations

- Currency: published ring prices use100rings/emerald, rounded upward to a payable merchant input. Where a source price is absent (lens colors, Hyper fruit, parts boxes, extra formerly unused toys), the code documents an authored Minecraft discovery price; source N/A classroom props are reward-only.
- Orange/GBA fruit must sit collectible and unowned on the ground for600ticks. One whole fruit unit produces one real DNA sample at the source-weighted probability; ownership target and pickup delays block conversion. Timers persist; repeated scans cannot consume the same unit twice. This substitutes samples for source temporary animal spawns/fruit bites.
- GBA per-bite Swim/Fly/Run/Power/Stamina values are multiplied by four for the existing whole-item console meal convention: orange30/-20/-20/30/10;blue20/50/-10/-10/30;pink40/-30/40/-30/20;green0/-10/30/40/20;purple-20/30/30/-20/10;yellow-30/40/-30/40/20;red30/10/30/20/-50. Ordinary feeding still checks appetite first.
- X eligibility/reset is sourced; the exact CWE level gain equation was not verified. The existing grade equation yields29–33points at X and is explicitly an adaptation, not a claim to reproduce source3560/3854 perfect-rebirth caps.
- Omochao assembly consumes four boxes and updates one real persistent robot: body, head, arms/key, then feet/active behavior. A stable builder token survives capture/rebirth; an unloaded or missing prototype is refused, never replaced by a duplicate. The genetic coat is copied, never trained skills.
- Egg Chao's source subsection states a1% offspring chance and rolling appearance; it does not state infertility. Treating Egg as an ordinary cosmetic lifecycle/breeding variation is an explicit interpretation.

## Current-version deltas reviewed

The current indexed page adds/clarifies64 configurable accessory slots/color editing, revised lucky births (hat or accessory), merged selectable garden slots, optional API-character disabling, new coffin acquisition via Dark Race, finer action/emotion configuration and the `.chao` guest import workflow. Minecraft uses real wardrobe categories, configurable births/rare behavior and its own world/garden storage. SA2 save-file import and24-slot memory-card restrictions are not portable mechanics. Newer downloadable garden packs and texture replacements are external SA2 mods, not bundled Minecraft content.

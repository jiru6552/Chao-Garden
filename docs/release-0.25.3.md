# Chao Garden 0.25.3

Minecraft Java 1.21.1 · NeoForge 21.1.219 · Java 21

This update implements the four requested scene changes and begins the Hero Garden as a playable space.

- **Neutral Garden:** the complete waterfall and pond are quarter-turned to the west side, facing east. The exit cave remains on the north wall. Existing compatible keeper props, garden registrations and saved bodies receive a preflighted migration; an unsafe migration stops before terrain writes.
- **Fortune-Teller approach:** each wall motif is a closed circle inside its wall tile. The purple hallway remains continuous through its corners.
- **Hidden Black Market:** a new metal Tool Cabinet has its own block, item, steel case, vents, hinges, handles and working paired leaves. Opening it reveals the stocked utility passage. The public wall stays cream with wood dado, without a Black Market sign or themed entrance arch. The existing resident trader and ordinary Market interaction remain behind it.
- **Hero Garden:** the hub's white staircase and balcony now lead to a separate garden with fountain pool, pale pavilion, broad lawn, pink cloud sea and distant bell island. Its east-wall portal returns to the balcony. Eggs, Chao, toys, fruit trees and garden providers use the same protected Adventure care rules as the Neutral Garden.

Hero Garden is a first playable interpretation of the SA2/Battle references, with scale chosen for Minecraft movement. It is not a recovered original-game mesh or a claim of exact game dimensions. The distant bell island is scenery; the central garden is the playable area. Dark Garden remains reserved.

All four authored realms reject ordinary wildlife. The original world return journal is retained through garden visits, and the central hub exit restores the keeper's original game mode and return position.

## Install

Replace the previous Chao Garden JAR with `chao_garden-0.25.3.jar` on the server and every client. No additional decoration mod is required. Existing Chao identities, eggs, carriers and compatible garden props are retained.

# Collection and icon revisions - 0.14.0

The active catalog now contains **19 themes**, including Nether and End. The 29 removed integrations have no active appearance, recipe, creative entry or themed art. Their old egg registry shells load only as hidden ordinary eggs for save compatibility. Existing Chao retain identity, ownership, care, animal parts and training while using their ordinary appearance. See [migration details](THEME_RETIREMENT_014.md).

Neo Vitae is the display name and `neovitae` is the actual required mod ID. `/chao variantegg neovitae` is the public command spelling; the old `blood_magic` saved identity remains compatible. This changes the integration requirement as well as the label.

Every retained theme uses matching native8 egg artwork and16px chest artwork. Nether and End replace the entire egg surface rather than adding a decal onto a different shell. The existing curved placed-egg geometry is retained. Reference textures were inspected, then redrawn as original pixel art; source-mod texture files and jars are not redistributed.

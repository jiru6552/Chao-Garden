# Car, dolls and pogo source notes — 0.25.49

These additions use the project's supplied SA2B `ChaoMain.prs` geometry and `al_toy.prs` textures, decoded offline with the existing `art/extract_sa2_02515.py` parser. They do not execute a game binary or add a runtime dependency. Source hashes, object offsets, original and emitted triangle counts, actual surface contacts and separate floor bounds are in `assets/chao_garden/models/active02549/manifest.json`.

The action-name reference is Exant64/CWE commit `0aea72e`'s `CWE/imgui_debug_motionstrings.h`; the release owner records the complete reference manifest. No frame-accurate game-footage comparison is claimed here.

World models are distinct from held models. The car rests on its wheels with the hood along the block's facing. Dolls lie face-up; the pogo lies flat with its handle toward the block's facing. All floor meshes have exact minimum Y=0. Original surfaces, UVs and material assignments are retained; source double-sided flags add corresponding back triangles. Inventory icons are renders of the actual adapted geometry. All four have explicit Minecraft crafting recipes and exactly one ordinary block drop; those acquisition rules are Minecraft adaptations.

The production session lasts 160 ticks. Root integration registers ordinary source-free car/doll once/loop/stop previews and a real-block pogo preview adapter. Hand props use only a temporary render stack, never a physical inventory copy. The production clock, Lionfish tracks, sound predicates and source reservation are shared with the previews. Server interruption, reward, care and cooldown behavior remains in the existing shared toy controller.

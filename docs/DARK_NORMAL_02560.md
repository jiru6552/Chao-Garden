This pass adds the full ordinary Dark adult family whose first type is Neutral (`NORMAL` in code and the Chao Island viewer): balanced, Run, Power, Fly, Swim, Run+Fly, Run+Swim, Power+Fly and Power+Swim. Reversed pair order is the same form. Swim/Fly and Run/Power remain opposing influences. The original blocky 7×6×6 head, working pixel face and shared 59-joint rig are preserved. ## Development and compatibility

Only ordinary living mortal Dark adults with locked Neutral first type select this asset. Current axes use `(Power - Run) / 960` and `(Fly - Swim) / 960`, clamped to -1..1, where training is `100 * level + progress`. The 960-net-progress threshold is provisional existing mod timing. Maturity separately blends a common fresh target into a mature 3×3 lattice; twenty-tick display easing handles edits. Training and reductions can develop or recede traits without making the Chao biologically younger. Baby training carries forward; no stats are reset or new save fields added.

Both ordinary and combined drives, decreases and Creative edits feed the same current bars. Existing worlds, controls, command authorization and synchronization retain their authoritative implementation.

Natural coats use the referenced age/variant colors; named, monocolor and jewel coats retain their underlying pigment and bounded details. The same model and targets apply to every coat. ## Boundaries and testing notes

Viewer settings guide shape and region placement, not original-game timing or exact interpolation. The final flat colors, three-section crest, rectangular low-resolution wings and six-spur cube marker are deliberate blocky approximations. Physical phone touch, an independent remote-player connection/latency/reconnect, shaders/resource packs/full modpacks, every accessory/animal/toy combination, listening and full natural-lifetime pacing remain untested. Save/reload checks exercise real entity NBT and authoritative encoding/handlers; they are not a claim that arbitrary user worlds or a full server restart were exercised.

Static actors are frozen and raised two blocks for the below camera; this is not natural hovering. Equal current Run/Power training unlocks the ordinary upright photo pose while preserving the net training axis. Cameras and native animation epoch match, but ordinary idle leans/blinks can differ. Motion front/side/rear camera phases occur at different ticks, rather than being simultaneous views of one instant. Native water coverage is stationary in-water animation, not autonomous swim travel.

Real equipped captures cover upright Creative flight. The player obscures parts of the Chao's face and marker in some views; this does not prove complete clearance for every player skin/helmet, horizontal elytra/swimming carry, takeoff or landing. Actual book and broom previews retain the existing grips and cleanup. The default passive full adult visual clock remains 14.4 active hours versus the ordinary twelve-hour adult life; care boosts or Creative maturity are needed to inspect the endpoint within an ordinary lifespan.

Use the same 0.25.60 JAR on client/server and retain Lionfish API 3.1. Start with a fresh baby that has never earned Swim, Fly, Run or Power points, move its Creative Analyzer alignment to -100 Dark, then use `/chao mature` or let its natural first evolution finish. Resetting displayed bars does not erase remembered first-evolution training. Confirm the adult's first type is Neutral before testing later specializations.

For that adult, `/chao ~ -100 Run 10` develops Run. A named example is `/chao "Shade" -100 Fly 10`. Main-stat levels accept 0–99; level 10 exceeds the provisional 960-net-progress full-axis threshold. Reset the opposing bar to zero for a pure endpoint, or set opposing bars equal for balance. Pair Run or Power with either Fly or Swim; reversed pair order is identical. Use the adult's actual locked alignment number, wait about one second after a large edit, and compare visual maturity 0/50/100% in Analyzer → Stats. Adult alignment remains read-only and conflicting command requests reject the transaction; maturity editing stays in the current life stage.

Existing previews remain available: `/chao testtoy picture_book once`, `/chao testtoy picture_book loop`, `/chao testtoy picture_book stop`; broom uses the same modes, and `/chao testtoy list` lists supported activities. They use the production timeline, grant no rewards and retain cleanup on stop/interruption. Silent visual recordings do not establish sound timing or listening.

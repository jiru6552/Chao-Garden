# Chao Garden 0.25.4

This release follows the supplied November 2 feedback and retains the existing Chao, garden, school and shop systems.

- **Neutral Garden:** waterfall and pond move fifteen blocks west. Solid mountain shoulders join the waterfall to the surrounding cliffs. The north, east and west edges are enclosed, leaving only the southern edge open. The north cave keeps its location and now has a two-block-deep stepped mouth, three blocks wide, with three-block sides and a four-block center. A rectangular 3×4 portal sits behind the mouth without a quartz frame.
- **Garden device:** the existing Garden Block becomes an actual eight-cell 2×2×2 device with matching per-cell geometry, support and placement checks. Every part opens the same garden provider. The Hero device faces the lawn. The CD uses a black vanilla-style record silhouette with a light blue and yellow center label.
- **Kindergarten architecture:** the existing column blocks form Ionic pillars with fluted shafts, bases and paired scroll capitals. The capitals meet the ceiling. School door trim is slimmer, its corners use the same cream wall material, and the leaves have stepped tops that fit the opening. Collision and selection follow the shaped leaves in every facing and open state. The hidden metal cabinet retains its rectangular construction.
- **Clinic:** move the portrait onto a backed wall, move the right curtain to the wall, place its hanging gold tie on the left, reverse the beds and medical machine, and rebuild exposed bed faces to remove overlapping surfaces. The corresponding right curtain in the Principal's office receives the same tie orientation repair.
- **Hero Garden:** orient straight and corner pavilion cornices so the floral underside follows each turn.

Existing authored rooms advance to revision 29 on entry. The fixed device keeps its original garden registry key. Legacy player devices remain readable; an unobstructed device can expand safely, while an obstructed footprint is left intact. Migration checks run before terrain writes and retain owned garden providers, Bell links, placed care objects and living Chao identities.

Install the same `chao_garden-0.25.4.jar` on the server and each client, replacing the old JAR. Minecraft Java 1.21.1, NeoForge 21.1.219 and Java 21 are required. Accessories and owo remain optional.

See [TESTING.md](../TESTING.md) for completed checks. The complete project retains editable assets, original feedback pictures and verification logs. Separate screenshot/video previews are omitted at the user's request.

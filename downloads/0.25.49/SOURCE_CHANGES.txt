Chao Garden 0.25.49

Cumulative source overlay: 330 changed/new files and 21 explicit deletions onto full 0.25.43 source. Includes all previous updates. This ZIP is not a standalone project. The delivery branch contains the complete updated project.

Extract files at the full project root, preserving paths. Then apply SOURCE_DELETIONS.txt by hand, or run:
python3 apply-source-deletions.py /path/to/full/Chao-Garden
The deletion helper refuses edited files and never touches Minecraft saves. Run it with --verify-only to review first.
Deleting the retired assets matters: extracting an overlay alone cannot remove old files.

Java 21, Minecraft 1.21.1, NeoForge 21.1.219 and external Lionfish API 3.1 are required. Use matching 0.25.49 client/server JARs.
Read TOYS_02549.md, TOY_REFERENCES_02549.md and COFFIN_RETIREMENT_02549.md for scope, references, migration and test limits.

# Official-addon Run construction reference

This is a read-only project-asset inspection, separate from the fresh live viewer research. The imported Run geometry, texture and converted official geometry were inspected; their exact hashes are in `official-asset-review.json`. The 128×64 texture was opened at a nearest-neighbor enlargement without changing the source.

The asset already uses the original 7×6×6 skull box. Its central crest uses a broad cuboid root and a smaller angled terminal section. Each mirrored rear-side spike uses another two stepped, yawed cuboids. That small construction vocabulary is appropriate for the requested Minecraft interpretation. Compact 2×2×2 hands and 2×2×5 feet provide a useful limb reference.

Its raised eye/brow replacement cubes and zero-thickness side and wing cards should not replace the current canonical face or closed production surfaces. The two small front-side nubs seen above/outside the eyes in the viewer need independent features rather than confusing them with the broad rear spikes. The old green/cyan/lime atlas is not a complete Neutral Run age or specialization palette: the live viewer changes balanced maturity toward blue, Run toward deep cobalt, and opposite Power toward magenta.

No geometry, texture, normals or morph code from the viewer or this inspection is automatically imported into the production model. The model agent is authoring a separate shared-rig blocky interpretation while protecting the canonical head, face and attachment transforms.

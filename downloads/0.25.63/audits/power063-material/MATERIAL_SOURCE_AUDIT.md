# Neutral Power 0.25.63 material source audit

The new scoped material uses the original canonical baby atlas and independent current maturity/Run–Power/Swim–Fly samples. Its cache is isolated under `dynamic/neutral_power063/`; resource reload and end-of-frame eviction follow the existing contained material lifecycle. No saved field, new renderer dependency or general-purpose API is introduced. Thirty-tick display easing is provisional until the actual shape-emitter displacement checks run.

I personally opened twenty-three fresh actual viewer originals: fresh front/side, three mature control side views and all nine mature front/back pairs. I also opened the complete twenty-seven-panel age-zero and age-half sheets, plus the five-age pure-Power side progression and all eight fixed-age training progressions. These views overlap. Fresh Power states converge on golden-orange body, yellow fists/orb, pale cream head/toe caps, hotpink front belly and tail end, and green torso back. Mature bodies stay orange/red; gold, salmon, pink and magenta caps/orbs/toes, gold or burnt-orange hands and green/gray/lavender torso-back regions distinguish the later targets. The full signed grid includes opposite Run without changing first Power identity. Half-age Power remains orange with peach/orange caps and orb before its strongest mature red. Timing varies by specialization, so linear age and bilinear training color interpolation remain explicit first-pass approximations. RGB values and flat blocky boundaries are authored visual estimates, not imported source texture pixels.

Power's actual reference has capped crown/rear/horn points, rather than Run's longitudinal forehead pattern. The original skull UVs remain unchanged and receive ordinary body pigment; there are no added forehead, side or head-top strokes. Four separate distal feature sections use one cap swatch, while roots use the body swatch. This preserves the prior request for a clear forehead without inventing Run stripes on Power. Original 0.25.62 head-top/central-crest stripes remain unchanged in that previous family.

Exactly four native source-transparent texels—x124..127 at y63—become opaque only in the new material: wing distal, wing root, head cap and feature body. All 172 original canonical coat PNGs were checked, for 688 transparent source samples. No source atlas or previous model is edited. The unused fourteen-pixel Run stripe tile is not painted in this profile. Natural two-tone pigments develop toward the observed Power family; named, monocolor and jewel bodies retain their inherited hue and finish. Original facial and other alpha pixels remain protected, and the orb pigment depends only on species development, independently of coat and shiny genes.

The original torso's front receives a compact chest patch; its back has an inset color region observed directly in the viewer. Feet retain body-colored heels with broad pale/pink toe caps. Head caps are simple colored distal cuboids; detailed source zigzag rings and soft gradients are deliberately simplified. The same semantic regions and geometry apply to every color and shiny variant.

The shiny path was traced rather than inferred from `textureOverlay`. `ChaoShineLayer` re-renders the actual `ChaoModel` with `ChaoShine.surface(OfficialChaoRig.texture(state))`. The new dispatch selects the dynamic painted material, including the opaque feature swatches. The reflection shader masks from that painted alpha and projects a continuous field from geometry. Raw original-coat `textureOverlay` belongs to the separate animal/variant/flame overlay rig, which does not contain the new Power head/wings. No shared shine-layer edit is justified by this source trace. It does not certify visible moving highlights in a native client.

The source audit records all image/source hashes, the 172-coat proof and 55 unchanged inherited material/region/model files. Only the root-owned `ChaoPaletteMaterial` dispatch differs from its parent baseline. Builds, geometry/pixel suites and actual native-client observations are separate evidence; this document does not declare them passed.

The initial new material probe failure was diagnosed from actual source pixels: torso-back pixel `(28,37)` is RGB `(208,227,113)`, darker than reference accent `(48,0)` at `(236,255,141)`. A fresh back palette `(140,225,104)` therefore paints `(123,200,83)` through the retained channel-ratio shader-independent tint. Comparing that probe to the unshaded palette record is incorrect; no product color or texture-detail change was made to satisfy the assertion. The corrected independent assertion passed for the pre-tail-cleanup source in the actual focused run (BUILD SUCCESSFUL in1m3s), with306,054,091 material checks; no product change was needed for that probe correction.

The corrected-horn native diagnostic then exposed a real tail semantic-color issue: the retained broad original base was pink while its narrower authored root was body-colored, forming a visible inset/rim. Root approved a new-profile-only paint correction. Original base island native[52,68)x[30,38) now uses body pigment with source shading retained; the new distal sample(50,32) stays tail-colored. Geometry, previous routes and the four alpha exceptions are unchanged. Pre-fix source/audits are preserved privately. The corrected source then passed the actual focused run in1m2s with320,389,960 material checks, including1,783,296 retained-base interior samples and4,644 independent root/tip samples each.

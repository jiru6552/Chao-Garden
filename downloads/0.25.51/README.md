# Chao Garden 0.25.51

[Download JAR](chao_garden-0.25.51.jar?raw=true) · [Source changes ZIP](chao-garden-0.25.51-source-changes.zip?raw=true)

Refines two-hand broom use, raises book/doll grips, corrects the official Shadow face mapping, improves three inventory icons, and adds prone floor drawing and one-hand lateral car play. Book, doll and crayon interactions are silent. Includes previous updates. Use matching client/server 0.25.51 and external Lionfish API 3.1.

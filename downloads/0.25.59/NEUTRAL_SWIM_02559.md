# Neutral Swim-first morphology — 0.25.59

This update adds the ordinary **Neutral / Swim-first** adult family: balanced, Run, Power, Swim, Swim+Run and Swim+Power. Pair order does not create another form. This is distinct from the existing Neutral/Normal-first Swim specialization. The original blocky 7×6×6 head box, pixel eyes, expression geometry, animation joints and canonical baby attachment/UV family remain in place.

Run raises the fins and trails the crown nearly horizontally; Power has short broad fins and stockier proportions; Swim develops long hanging flippers and a dropped rear hood. The paired fins use two blocks each and coarse flat face colors in place of curved leaves and zigzag borders. These simplifications retain the Minecraft construction style and are explicit refinement candidates, not claims of exact source fidelity.

## Development and compatibility

First evolution still uses the greatest earned-point total among Swim, Fly, Run and Power, with the most recently actually raised tied ability winning. Stamina is excluded. Adult alignment and first type stay locked. This profile applies only to living ordinary Neutral adults whose locked first type is Swim; it does not reinterpret a Normal-first adult as Swim-first.

Later Run/Power influence is `(Power current progress - Run current progress) / 960`, clamped to -1..1. Swim/Fly is `(Fly - Swim) / 960`, clamped to -1..0 for this six-form update. Fly therefore cancels later Swim toward balanced Swim-first; excess Fly does not invent an unimplemented Fly specialization or change the locked first type. Current progress means `100 × level + progress`, not remembered first-evolution points. Compatible axes combine at one shared target.

The 960-net-progress threshold is the existing provisional mod rate, not timing measured from the viewer. The viewer’s compatible diagonal appears to reach its mixed endpoint relatively early; this pass retains the existing bilinear mod progression rather than claiming an exact match to that undocumented formula. Maturity uses the existing adult visual clock independently. At maturity zero all training selects the same fresh Swim-first surface. Baby training carries forward; lowering a stat can recede specialization without lowering biological age. The existing twenty-tick display easing handles large edits. Ordinary/combined drives, decreases and Creative edits feed the same current bars; no new saved fields, stat reset or save migration is added. Existing biological timing is unchanged: full passive visual growth requires 14.4 active hours against the ordinary twelve-hour adult lifespan, so care boosts or Creative maturity are needed to inspect that endpoint within an ordinary lifespan.

Natural coats use Swim-specific crown/face/fin/wing accents. Named, monocolor and jewel coats keep their inherited skin and bounded details; shine remains the existing finish. The same geometry is selected for all coats. Four unused atlas swatches provide feature colors only in this profile; facial features and source alpha remain protected elsewhere. Existing Hero/Run, Hero/Normal, Neutral/Normal and baby assets remain byte-identical to delivered 0.25.58.

The Analyzer’s new family labels and read-only Growth meters reflect the same current influences. Existing Creative alignment and maturity controls and `/chao` testing commands retain server authorization and saved-state behavior. Adult alignment remains read-only; a command requesting a conflicting adult alignment rejects the transaction. Maturity editing stays inside the current life stage and does not itself cause death, reincarnation or another first evolution.

## Testing the family

Use matching 0.25.59 client/server JARs and external Lionfish API 3.1. Start with an ordinary baby, set Neutral and train Swim before first evolution, for example `/chao ~ 0 Swim 10`. An operator can use `/chao mature`, wait for its cocoon and confirm the locked Swim first type. Resetting displayed bars does not erase remembered first-evolution training history. Set maturity under Analyzer → Stats to compare fresh, half and mature appearances.

For a Swim-first adult, `/chao ~ 0 Run 10` develops Run and `/chao ~ 0 Power 10` develops Power. Set opposing current bars equal for balance; set Fly to 0 and Swim to 10 for later Swim. Swim+Run and Swim+Power combine those net axes. Main-stat command levels are 0–99; level 10 exceeds the provisional 960-progress full-axis threshold. Use the adult’s actual locked alignment number, and wait about one second after a large edit.

Representative existing preview controls: `/chao testtoy picture_book once`, `/chao testtoy picture_book loop`, `/chao testtoy picture_book stop`; broom uses the same modes. They use the production timeline, grant no rewards and retain their existing cleanup rules. Silent captures do not establish listening, physical phone controls or independent multiplayer latency.
